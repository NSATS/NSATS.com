Technical themes

Follow a technical subject through the pages that explain it. These routes connect high-level ideas to implementation and application questions within each portfolio.

Computing operations and memory

Quantum-Classical Computing introduces operations informed by quantum mechanics. Reversible Computing retains data within the circuit, so an output can be traced back to its input and the input recovered. Memory and RAM connects those operations to the working data a program needs, with classical data encoded using quantum-mechanical logic. Processor architecture places the operations within a larger design; the internal-bus pages explain connections, including the quantum-classical bus.

Quantum-Classical Computing →Reversible Computing →Memory and RAM →Processor architectures →

Information capacity and movement

Temporal compression increases effective capacity: more data can be stored or retrieved within the same physical storage resource. The physical size of the drive stays unchanged. Classical data is encoded using quantum-mechanical logic, and reversible computing contributes to compression.

The increase depends on the drive, how the licensee uses the technology and where the licensed gates, buses and computational technologies sit in the licensee’s design. For both existing drives and RAM, the licensee adds a specially designed classical chipset or controller built with the licensed technology. It encodes the data and manages the intermediate operations when information is stored or retrieved. The drive or RAM itself remains ordinary classical storage. This is not a software-only upgrade or a drop-in change; integration is part of the licensee’s design.

Effective capacity depends on processing time, not only physical size. A temporal drive is better described by how much data it can process and store per second than by a fixed capacity.

NSATS sells technology licences, not chips. Its technology helps licensees manufacture their own chips.

Data Movement examines the exchanges required within a task. Quantum-Classical Networking places quantum-classical network cards at both ends of a connection, with data passing through ordinary routers in between. These subjects distinguish holding information from supplying it where it is needed.

For a transfer between computers, follow Quantum-Classical Networking through both endpoint systems and the receiving application.

Temporal Compression →Data Movement →Quantum-Classical Networking →

Positioning and system use

Within Geomagnetism, start with location determination from Earth’s magnetic field. Operating environments explain the intended underground, surface, airborne, underwater, indoor and dense urban contexts. System integration then connects a position output to an application, and evaluation guidance examines how to assess its usefulness for a defined task.

The evaluation-methods page explains the comparison reference and the observations recorded during an assessment.
