This is a documentation walkthrough. You can read it and complete the exercises without installing software or connecting equipment.

Magnetometer walkthrough

SDK design documentation. Draft 2 · 9 October 2026

The walkthrough describes a custom eight-antenna magnetometer interface: connect to the intended device, log in, inspect the configuration, request a reading and disconnect. Each channel keeps its own identity and status. Processing, calibration and self-tests are separate tasks with their own prerequisites.

Device authentication belongs to the magnetometer and is separate from MyNSATS sign-in. The website does not connect to, authenticate or control hardware. The commands are illustrative design forms, not executable instructions or a method for computing position.

Walkthrough at a glance

Use this table beside the developer walkthrough. Trace the illustrative requests and check what must be known before the next step. The commands are design forms, not executable instructions. A device reference and its supported authentication mechanism would be needed for an implementation.

StepIllustrative requestConfirm before continuing
Connectconnect DEVICE_REFERENCECommunication is established with the intended device; connection alone does not grant measurement access.
Log inloginThe device mechanism confirms access and permissions. Stop if that mechanism is unavailable.
InspectdescribeIdentify the eight-channel mapping, representation, timing, applicable calibration and effective configuration. Keep missing metadata explicit.
Read onceread once channels=allEach of the eight channels has its own identity and status; a partial acquisition identifies missing data.
Optional streamstream start channels=all; stream stopStreaming requires device and adapter capability. Delivery, buffering and overflow handling remain undefined; confirm the effective settings and stop outcome.
Closelogout; disconnectDistinguish local closure from confirmed equipment state. Disconnection alone does not prove acquisition or a signal source stopped.

After reading, you should be able to distinguish connection, authorised access and interpretable acquisition. Continue with Exercises 1–3 and the averaging exercise; use the full walkthrough when a step needs explanation.

Before you begin

Read the walkthrough with the command reference beside it. Be ready to distinguish the device connection from authorisation, an individual channel from the complete acquisition, and a missing observation from a numeric zero. The hardware and data interface explains the record fields used in the exercises.

First example

Trace connection and login in Exercise 1, then inspect the eight-channel record in Exercise 2. Use Exercise 3 to explain what changes when a channel has no usable result. For each step, identify the information needed before the operation and the status returned afterwards.
