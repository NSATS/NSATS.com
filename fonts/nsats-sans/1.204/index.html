NSATS Sans 1.204

Version 1.204 · Released 3 November 2026 · Six styles · 388 encoded characters per style

NSATS Sans is NSATS’s typeface for websites and documents. This release provides Regular, SemiBold and Bold weights, each with upright and italic styles. The desktop files use TrueType format (TTF), while the compressed WOFF2 files are intended for websites.

Download fonts (ZIP) Web developer kit (ZIP) Documents, print and design kit (ZIP)

Changes in version 1.204

Version 1.204 corrects accent placement and spacing for ď ľ ť Ľ and adds a kerning table for older Windows applications, including Word 2010. Kerning adjusts the spacing between particular pairs of characters. In Word, enable “Kerning for fonts” to apply these adjustments; the release notes explain the remaining limitations when kerning is disabled.

Every other letter, width and kerning pair remains unchanged from version 1.203. NSATS Clear 1.100 remains available.

Testing and limitations

The release notes distinguish tests of earlier fonts and development candidates from checks of the final 1.204 files. They record measurement and Linux rendering checks for the released fonts, together with an independent review that included Safari on macOS. They do not record testing of the released files on Windows or installation of those files on a Mac; mobile checks also remain outstanding.

Read the release notes for the applicable test scope and known limitations. The specimens below show the six styles; they are not test results.
