Download fonts (ZIP) Web developer kit (ZIP) Documents, print and design kit (ZIP)

NSATS Sans is the new name of NSATS Clear. Version 1.203 has the same letters, spacing and kerning as the reviewed 1.202 design. You may download, install and redistribute the fonts under the SIL Open Font License 1.1; keep OFL.txt with them. Read the release notes for known limitations and untested platforms. The earlier NSATS Clear 1.100 remains available.
