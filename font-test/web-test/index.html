NSATS Clear font test

This page checks how the six NSATS Clear styles (Regular, Italic, SemiBold, SemiBold Italic, Bold, Bold Italic) behave in your browser, with the full Western European character set (234 characters). It takes about fifteen minutes. Run it once on each device and browser you are asked to cover. This is a test, not production approval.

How to run the test

  1. Open this page on the device and browser for your test row (table below). Open it in the browser itself, not inside another app, where you can.
  2. Fill in Your setup. Take the browser version from the browser's own About page.
  3. Wait for Automatic checks to finish. They run by themselves.
  4. Look at each test sheet and choose Pass, Issue or Not sure. Add a note for anything that looks wrong.
  5. Take a full-page screenshot, then press Save results. If saving is not available to you, press Copy results and send the text and the screenshot to A.

T8

Spacing and line breaking

The amounts in the first two boxes use non-breaking spaces (the second a narrow one, as in French), so each should stay together on one line inside its narrow box. The third box holds a long word with hidden hyphenation points: where it breaks, a hyphen should appear at the end of the line. The last line has a hidden hyphenation point too, and should show no hyphen.

T12

Western European text

Real words in the languages this set covers, then the symbols. Accents should sit clearly over or under their letters, never touch the letter above or below, and look the same from line to line. Spacing between letters should look even. The French lines use a narrow space before ? ; ! and inside « ».
