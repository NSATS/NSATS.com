NSATS Clear font test

This page checks how the four NSATS Clear styles (Regular, Italic, Bold, Bold Italic) behave in your browser. It takes about ten minutes. Run it once on each device and browser you are asked to cover. This is a test, not production approval.

How to run the test

  1. Open this page on the device and browser for your test row (table below). Open it in the browser itself, not inside another app, where you can.
  2. Fill in Your setup. Take the browser version from the browser's own About page.
  3. Wait for Automatic checks to finish. They run by themselves.
  4. Look at each test sheet and choose Pass, Issue or Not sure. Add a note for anything that looks wrong.
  5. Take a full-page screenshot, then press Save results. If saving is not available to you, press Copy results and send the text and the screenshot to A.
