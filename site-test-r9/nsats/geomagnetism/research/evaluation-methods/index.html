How positioning is evaluated

A proposed positioning evaluation should answer a clear application question. Define the location information needed, the operating conditions and the reference against which the implementation will be assessed.

Set the task and reference

Identify the equipment or object to be located and the route or positions involved. Select a suitable independent reference and record how it is used. Distinguish inputs to the positioning implementation from information used only to assess its output.

An operating input participates in producing the position output; assessment-only information does not enter the implementation.

An independent reference supplies comparison information separately from the output under examination. Comparing an output with a copy of itself would give agreement without an independent check. The reference also needs to concern the same object and observation event. If equipment moves between observations, that movement must be accounted for when identifying which positions are being compared.

A comparison reference has its own uncertainty and conditions of use. An assessment should explain how the reference was obtained and what limits apply to it. A difference between an estimate and a reference therefore needs both records for interpretation, rather than treating the reference as a description with no uncertainty of its own.

Record the operating conditions

Describe the platform, implementation version, installation, motion and environment. Include relevant setup and initialisation conditions. A repeatable record allows differences between trials to be examined and helps explain which situations the study represents.

Movement determines which places and stages of work the observations represent. A report should identify the equipment’s mounting and any repositioning, and connect movement or mounting changes to the observations collected under each arrangement.

In an evaluation record, setup and initialisation describe preparation before the task begins, while any restart or configuration change during observation is recorded as part of the work actually performed.

Other activity can be present while an assessment runs. Equipment may carry out additional software tasks, communicate with another system or change its operating state. The record should identify the activity relevant to the assessment and whether it stays constant or changes. A change in shared activity is then distinguishable from a change to the positioning implementation itself.

Measure useful behaviour

Select measures and records relevant to the task:

  • Consider: the difference between estimated and reference positions.
  • Consider: the time to obtain a useful result.
  • Consider: the frequency of position updates.
  • Consider: the consistency of performance along the task.
  • Record: occasions when output quality changes or cannot support the application, alongside successful observations.

Frequency of position updates means how often a new position is supplied; time to a first useful estimate concerns the wait before the application can begin using location. For a moving platform, that initial wait and the spacing of later updates affect different parts of the task. The record needs to relate the first usable estimate to the start of the activity and later updates to the movement during it.

A summary can combine observations from different parts of a task. That can hide whether variation was spread across the work or concentrated in a particular stage. An assessment can retain the individual observations and group them by the conditions represented, so the summary remains connected to the work from which it was calculated.

Relate results to use

Interpret the results against the application’s needs. An inspection record, an operator display and another system input may have different requirements. This proposed framework provides a basis for planning an assessment; each implementation needs an appropriate task and method.

An assessment criterion describes the behaviour needed for the intended use. Defining it before the work begins separates that requirement from an explanation chosen after seeing the results. Where several uses are examined, each can have its own criterion. A finding relevant to one use need not answer the question posed by another.

A reviewable method records how observations were selected and how any summary was calculated. If an observation is excluded, the record should state why. Another reviewer can then follow the reasoning from the recorded work to the stated conclusion and identify which parts depend on judgement rather than direct observation.
