  • All three white-on-action pairs exceed 4.5:1 for normal text.
  • None of the three accents works as normal-size text on white: keep accents decorative, or put dark ink on them.
  • The pale rule is not enough as the only boundary of an essential form control; use muted text colour for input borders.
