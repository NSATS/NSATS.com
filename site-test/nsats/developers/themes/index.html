Themes

NSATS uses two kinds of theme: technical subjects that connect the technology, and interface or design approaches for presenting applications. Each serves a different part of understanding and developing a system.

Technical themes

Computing operations, working memory and data movement are connected themes within Quantum. Positioning, operating environments and integration form a separate set within Geomagnetism. Following a theme helps readers understand the relationship between subjects without needing to read every page in a portfolio.

The technical reading routes group security with implementation questions and positioning with system use.

Technical themes →

Interface and design themes

An application must present information in a way its users can understand. Design themes concern the visual and interaction choices used for tasks such as reviewing a computation or interpreting position information. The application’s purpose should determine what is emphasised, explained and made available for closer inspection.

In an application interface, emphasis controls what a user notices first; interaction determines what happens when that user selects a control. A prominent result and the control used to inspect its details have different jobs. The result needs a clear meaning at a glance, while the control needs a label that makes the next action predictable.
