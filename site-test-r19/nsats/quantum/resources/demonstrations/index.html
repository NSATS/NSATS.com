Temporal Compression

Follow a sample file through an illustrated receipt and storage sequence, then fetch the sample from the website and check its fingerprint in your browser. Scenarios cover research datasets, maintenance records, completed sensor intervals, analysis inputs and document selection. Read the comparison source to distinguish an unchanged returned copy from the revision or original required by an application.

Open the Temporal Compression illustration →

Further demonstration records

A record of a Temporal Compression run would give its date, a description of the set-up, stage times as recorded, and the original and returned fingerprints as recorded. It would also give the original and stored size of the file in bits as recorded. The tracking code used to request the file would be withheld. The record would state whether the original and returned files are offered and explain its limitations, including that a single run does not measure capacity or processing rate.
