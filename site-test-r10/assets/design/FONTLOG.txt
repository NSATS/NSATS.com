FONTLOG for NSATS Clear (Regular, Italic, SemiBold, SemiBold Italic, Bold, Bold Italic), version 1.100
======================================================================================================
All six styles: release candidate 04.

This file provides information on the changes made to this font software. It is provenance information; it is not an OFL requirement.

Basic information
-----------------
- NSATS Clear is a modified version of IBM Plex Sans 3.005, licensed under the SIL Open Font License 1.1 (see OFL.txt).
- It is not affiliated with or endorsed by IBM.
- "Plex" is a Reserved Font Name and is not used in any font name.

Repertoire
----------
Version 1.100 covers 234 characters (the Tier A Western European set; source/Repertoire manifest - Tier A.csv):
Basic Latin, Latin-1, Œ œ Š š Ž ž Ÿ ƒ ˆ ˜, the full Windows-1252 code page, and ‐ ‑ ‚ „ † ‡ ‰ ′ ″ ‹ › ⁄ № ≈ ≠ ≤ ≥ ✓,
thin space and narrow no-break space. Version 1.000 covered the first 122 of these.

Changes from IBM Plex Sans 3.005 (summary)
------------------------------------------
- Redrawn or refined glyphs:
  - figures 0 1 2 3 5 7
  - capitals C G K M Q R S
  - lowercase a c e l r s t
  - é è ç
- Lowercase vertical proportions: x-height 538 (inherited lowercase transformed; horizontal metrics unchanged).
- Spacing: approved changes for K M R a l r 3 (Regular) and K M R S a l r 3 c (Bold); see Phase 1 Build, Milestone 1.
- New: ½ ¼ ¾, built from NSATS figures, with fraction spacing approved 30 Sep 2026. ® ™ ← → are the Plex outlines.
- New: proportional figures as an OpenType option (pnum); tabular figures remain the default (tnum returns to them).
- Italic and Bold Italic: a designed 11-degree slant of the NSATS uprights (IBM Plex Sans Italic's angle), with an optical correction for round letters (O Q o 0 ö). Same advances, kerning and features as the uprights. Not the IBM Plex Sans Italic outlines.
- SemiBold and SemiBold Italic: weight position 0.704 between Regular and Bold (IBM Plex Sans SemiBold's own position). Glyphs unchanged from Plex use the Plex SemiBold outlines (with the lowercase transform where applicable); NSATS-redrawn glyphs are interpolated between NSATS Regular and Bold. Kerning by the same method from Plex SemiBold; K-V -15, K-Y -11. Names: family "NSATS Clear SemiBold" (style-linked Regular/Italic) within typographic family "NSATS Clear"; weight 600. SemiBold Italic is the same 11-degree slant.
- Western European characters (version 1.100): IBM Plex outlines for symbols and for letters NSATS did not redraw (lowercase
  through the x-height transform); accented letters are NSATS base letters with accents centred on the base (on a, over its
  top half), lowercase accents raised with the x-height; ¹ ² ³ ª º ¢ æ œ built from NSATS parts and spaced by the Phase 1
  rule (æ shares NSATS a's straight stem with NSATS e, as IBM Plex Sans's own æ does); the dotless i is an unencoded component; the soft hyphen is drawn as the hyphen.
- Kerning: IBM Plex pairs transferred pair by pair. Inherited pairs keep Plex values; pairs involving redrawn letters are adjusted. Bold K-V and K-Y loosened (-15, -10).
- Hinting: none. A minimal 'prep' enables smart dropout control. Stray glyph instructions imported from Plex were removed.
- Metadata: names "NSATS Clear"; version 1.100; Windows-1252 code page declared (complete coverage).

Known limitations
-----------------
- Bold zero has a recorded small-size limitation at 11–16 px (scope §6). Zero width-mark study 01 (30 Sep 2026) found no condition that passed its agreed gates; the accepted zero is kept.
- Characters outside the 234 (for example Central European letters such as ł, ő, č) fall back to another font.
- The soft hyphen maps to the visible hyphen glyph (the manifest rule); its behaviour in apps is under test.
- The fraction slash (U+2044) does not build fractions: 1⁄8 shows full-size figures. Use ½ ¼ ¾, or 1/8.
- Untested:
  - Microsoft Word (Windows/Mac), including AutoCorrect
  - Windows DirectWrite/GDI
  - macOS native applications
  - iOS/Android
  - website environments W1–W7
  - physical print
  - hinted rendering
  - reader studies


6 October 2026 — NSATS Clear 1.200 CANDIDATE, not owner-approved.
Built in an isolated folder from the approved 1.100 sources; no 1.100 file changed.
Added full Latin Extended-A and the 19 missing non-PUA Mac Roman characters; 388 encoded characters total. Added 15 zero-width combining marks and contextual cap variants, dotless alternates, ccmp, mark and mkmk. Retained existing pnum/tnum and kern lookups. New letters are derived from IBM Plex Sans 3.005 with the documented NSATS lowercase transform and 11-degree italic slant; barred forms use NSATS bases, and new accents use NSATS bases. Corrected candidate-only barred-letter fragments and detached ogonek joins during development.
Strengthened only the inner zero marks (tabular and proportional) in Bold, Bold Italic, SemiBold and SemiBold Italic; no existing advances or kerning changed. Added typographic family names to R/I/B/BI, and STAT to all six. Retained SemiBold legacy family grouping. Added separate ttfautohint Windows TTFs with identical geometric outlines, metrics and names; primary TTF and web WOFF2 stay unhinted.
CoreText and HarfBuzz NFC/NFD checks pass for this candidate, within the documented test boundaries. Windows, mobile, Word, physical print and reader acceptance remain open. See REPORT.md; this entry is not production approval.


6 October 2026 — NSATS Clear 1.201 CANDIDATE, not production-approved.
Owner-approved N1 repair of the 1.200 candidate (Claude verification Addendum 01/02; Option B approved the same day), built in a new folder. No 1.200 or 1.100 file changed.
Only change: the top (class 0) mark-to-base anchors of the 68 precomposed capitals that carry a top accent (all except Ľ) now sit above the existing accent: y = max(698, yMax − 12 + Δ), Δ = 18 (Regular, Italic), 20 (SemiBold, SemiBold Italic), 21 (Bold, Bold Italic); x follows the 1.200 build's centre function, including the 11-degree italic offset. A second combining mark after an accented capital (e.g. Ê + U+0301) no longer collides, with clearance at least that of the matching lowercase stack.
No outline, advance, metric, kerning, GSUB, GDEF, cmap, mkmk or lowercase anchor changed. Name IDs 3/5 and head.fontRevision read 1.201. Hinted fonts regenerated with the recorded ttfautohint 1.8.4.16-eb64 parameters; their hinting is identical to 1.200's.
Disclosed: such out-of-repertoire capital stacks reach 1,260 / 1,302 / 1,321 units (Regular-Italic / SemiBold / Bold pairs) against the unchanged usWinAscent 1,025; application clipping is untested. Native CoreText, Windows, mobile, Word, physical print and reader acceptance remain open. See REPORT.md; this entry is not production approval.


6 October 2026 — NSATS Clear 1.202 CANDIDATE, not production-approved.
Built in a new folder from the 1.201 candidate under the owner-approved revised scope (original recommendation, Revision 01 and Revision 02; S0-B with τ basis (i); Kï values approved the same day). No 1.201, 1.200 or 1.100 file changed.
Changes:
- N3: OS/2 code-page bits now declare Windows Central European (1250), Turkish (1254), Baltic (1257) and Mac Roman alongside Western (1252); ulCodePageRange1 = 0x20000093. Coverage of every declared page is complete.
- N2: a supplementary kerning lookup gives the Latin Extended-A letters added in 1.200 the kerning of their base letters (Revision 02 proxy rules). Each new pair was tested for collision and against a frozen per-face minimum spacing (τ) taken from the shipped Latin-1 accented pairs. Pairs that would collide or crowd were reduced; pairs that collide even unkerned were held (no kerning added) for later owner decisions. No opening (positive) kerning was added. Existing kerning is unchanged except Kï.
- Kï: SemiBold and SemiBold Italic +12 → +27, Bold and Bold Italic +16 → +37 (removes an existing overlap of K's arm and ï's dots; owner-approved values). Regular and Italic unchanged.
- Name IDs 3/5 and head.fontRevision read 1.202.
No outline, advance, metric, mark positioning, GSUB, GDEF, cmap or hinting instruction changed; the hinted fonts keep 1.201's hinting tables byte-for-byte.
Open: native CoreText for 1.202, Windows (including the effect of the new code-page bits), mobile, Word, physical print, reader acceptance, native-language review, and owner decisions on HOLD and positive-source pairs. See REPORT.md; this entry is not production approval.
