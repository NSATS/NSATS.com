NSATS Geomagnetism

NSATS licenses technology that determines location using Earth’s magnetic field. Licensees can incorporate the technology into their own chips, embedded hardware, devices and systems intended for operation underground, on the surface, in the air, underwater, indoors and in dense urban areas.

Location from Earth’s magnetic field

Location information helps an application associate equipment or an observation with a place. A compass heading answers a different question: which direction something faces. NSATS’s geomagnetic technology determines position using Earth’s magnetic field, for tasks that need a location input without relying on live GPS satellite signals.

In application software, a location input supplies the place information needed for the task being carried out.

Underground

Underground use is an intended direction. Mines, tunnels and enclosed infrastructure create a need to locate equipment and associate work with a place. Geomagnetic positioning supports licensees developing inspection devices, mobile equipment or personnel devices for these settings. The useful location requirement depends on the task: finding an asset, recording an inspection or supporting an operator’s understanding of position.

An underground inspection record can distinguish an area that was examined from one merely passed through.

Underground, on the ground and in the air →

On the ground

Surface vehicles, mobile robots and industrial assets are further intended applications, including equipment operating indoors and in dense urban areas. A licensee can use a location input based on Earth’s magnetic field alongside the other information a system uses. Applications range from equipment moving through a site to inspection vehicles linking observations to positions along a route.

Workplace software needs the task state as well as the equipment’s location to distinguish travel, work and waiting.

In the air

Aircraft and aerial inspection drones are another intended setting for geomagnetic positioning. A licensee can include a geomagnetic input within a system’s navigation architecture, particularly where reduced reliance on live GPS signals is important. Evaluating this application requires attention to the aircraft, its motion, operating environment and the requirements of the equipment using the position.

An airborne platform is any craft with the capability to carry the equipment in flight. Its navigation architecture is the arrangement of functions that supply and use information about movement and location. In an inspection application, the aircraft’s route, the observation being collected and the information presented to its operator are connected tasks, each with its own software responsibilities.

Implementation under licence

The licensed technology can be incorporated into licensees’ chips, embedded hardware, devices or a wider software and hardware system. The licensee’s application determines what position information it needs and how that information will be used. NSATS sells technology licences, not chips. Its technology helps licensees manufacture their own chips.

An implementation brief can identify who will use the location information and the action that follows. For an operator display, that includes what the person must recognise; for a stored record, it includes what someone must find afterwards. The equipment designer can then identify the hardware and software work needed to serve that use.

Positioning resilience

For equipment that depends on location, resilience concerns the position information available when operating conditions change. A source that works without live GPS broadcasts offers a different input for the system designer to consider. Its contribution depends on the device, software and environment, including how the application uses the position it receives.

In a location-dependent application, losing a current input and losing the ability to complete the task are separate events; the equipment’s response determines how the interruption affects the user.

Location in an operational task

An inspection system can store position alongside a finding so that the observation can be related to a place. Mobile equipment can present location to an operator. These examples show how a positioning function can contribute to a larger system, with integration shaped by what that system needs to do.

In an illustrative inspection, a device saves a position with a finding, then moves elsewhere. The saved entry keeps the place at which the finding was made. An operator’s current-position display follows the device, so its changing value must not overwrite the finding’s stored location.
