Positioning without GPS satellite signals

NSATS’s geomagnetic technology determines location without relying on live GPS satellite signals. It provides a position source based on a different physical input for applications that need one.

Here, “live” means broadcasts received from the satellites at the time positioning is performed. A physical input is a measurable quantity present in the environment; satellite radio signals are one kind of physical input.

Why an alternative input matters

A system’s positioning requirements can extend to places or circumstances where GPS reception is unavailable or unsuitable for the task. Underground, underwater, indoor and dense urban use are intended directions for NSATS’s geomagnetic technology. An independent location input can form part of the system’s positioning design. Its useful contribution depends on the application and the performance of the implemented method.

A positioning design identifies the inputs the system uses, the role of each input and how the application uses the resulting position. In an equipment design, the part supplying location information and the part acting on it can have different responsibilities. The design description connects those responsibilities to the task being performed.

GPS satellites transmit radio signals, and a GPS receiver uses information in the received broadcasts to calculate position. Reception at the device depends on the path of those signals to its antenna. Obstructions can block signals, while reflections can change the received signal path. These are features of satellite reception that a system designer considers for the task’s operating setting.

In an ordinary location application, obtaining a position and sending it elsewhere are separate activities. A receiver supplies information locally; a separate communications connection is needed to send it to a remote recipient. A local display and a remotely monitored device therefore involve different surrounding equipment, even when both use location information.

Define the system’s dependencies

For an evaluation, identify the inputs used by the positioning function during operation and setup. Also identify how the surrounding system combines or acts on position information. This makes the intended GPS-independent role clear within the complete design.

In general system engineering, setup prepares equipment for work, while operation is the period in which it performs its task. An input used during preparation can have a different role from information consumed repeatedly during use. An assessment can record each input’s role and when it is present, including inputs supplied to surrounding application software.

An evaluation record identifies the operating mode, the combination of functions and inputs selected for the task, so observations refer to the arrangement actually used.

How positioning is evaluated →

Position as a system input

A location estimate can be displayed, recorded or used alongside other system information. The application determines which of these roles it serves. A geomagnetic input should therefore be considered in the context of the task and the way the surrounding system uses position.
