Positioning from Earth’s magnetic field

NSATS’s geomagnetic technology is designed to use Earth’s magnetic field to determine location. It supplies position information as an input to a licensee’s device, software or wider system.

Earth’s magnetic field is a physical field with measurable strength and direction. Strength describes the magnitude of the magnetic influence at a place; direction describes its orientation. Earth’s magnetic field varies in strength and direction from place to place and changes slowly over time. A magnetic measurement describes that field. Position information is information that an application can relate to a location.

What location information enables

A position allows an application to associate an object or observation with a place. An inspection system can attach location to a finding; an operator’s display can show where equipment is situated. The application determines the kind of position information that is useful and how it is presented or acted upon.

In ordinary positioning, a position estimate is a reported location derived from observations. It is assessed by comparing it with a suitable independent reference. A detailed-looking output and an accurate output are different things: the amount of detail displayed does not establish how closely the estimate agrees with the location being assessed.

Accuracy concerns agreement with the location used as a reference. Repeatability concerns whether repeated observations under the same conditions agree with one another. A system can be repeatable while retaining a consistent difference from the reference. Uncertainty describes the doubt associated with an estimate under stated conditions. These concepts explain why an assessment needs the reference and conditions as well as the reported position.

Position and direction

A compass heading describes direction. Positioning addresses where something is located. For a prospective implementation, the requirement should describe the location information the application needs, rather than assuming that an orientation measurement provides the same answer.

A magnetic compass heading is measured relative to magnetic north. Geographic north is the direction towards the planet’s geographical North Pole. The angle between those references varies with place and is called magnetic declination. A heading therefore needs its north reference to be understood correctly.

An ordinary handheld device can turn while remaining in the same place. Its heading changes, although its location does not. A device can also move while continuing to face the same direction. Describing where an object is and where it faces therefore requires different information, even when an application uses both together.

Heading also differs from direction of travel. An object may move sideways or backwards relative to the way it faces. A display that uses an arrow needs to establish which meaning the arrow carries. A location record identifies a place; the application decides whether an orientation or movement indication is also relevant to the task.

The role within a device

Position determination is one function within a larger design. The surrounding device handles how information is displayed, recorded or supplied to another component. NSATS licenses the positioning intellectual property for integration into such implementations.

Positioning intellectual property concerns rights in protected designs for determining location, which can be licensed for use in an implementation.

In a software application, receiving location information is followed by application work. A display may relate it to a named working area; a record may associate it with an event; another function may use it to select relevant information. Those actions concern what the recipient does with the output. They can be specified in the language of the user’s task.
