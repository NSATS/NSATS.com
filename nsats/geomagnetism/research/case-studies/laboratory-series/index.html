A laboratory series: eighteen monthly runs at 1 m/s on a closed loop

Summary

This case is built on a synthetic sample — not a measurement — to fix the record’s layout; it is published as a labelled illustration and is replaced by recorded runs as they are approved. The laboratory case asks about repeatability of the per-point deviation band across a monthly series on a closed loop. Synthetic entries illustrate how to read each run’s reference, sensor tracks and deviation summary in sequence. The band is read per run, without a trend calculation. These generated values establish neither measured repeatability nor behaviour outside the laboratory.

What this case aims to show

The assessment question is whether the per-point deviation band is repeatable across a series of laboratory runs. In this synthetic sample — not a measurement — the ordered records illustrate how to read the band within each run under the stated laboratory conditions. They supply no observed change or repeatability result over time.

The arrangement

The laboratory reference instrument is a rail position encoder. In the synthetic sample — not a measurement — the arrangement follows a closed loop of about 5 m radius and about two laps. The sample represents 8 sensors, identifies the software version as SAMPLE and uses one start-point code, GLC-007. Reference and calculated positions are metres north and east of that start point.

The task

The synthetic sample — not a measurement — represents eighteen monthly entries, one per month, presented as run 1 of 18 through run 18 of 18. The sequence follows G-SAMPLE-L01 through G-SAMPLE-L18; only the start time of day appears for each entry.

The nominal speed is 1 m/s throughout the sample series. Each entry lasts 60 s, uses a 2 s interval and contains 31 points, including the start, for 8 sensors. The laboratory setting, reference type, software-version label and start-point code also stay the same. Each run retains its own reference and calculated tracks and its own deviation summary.

How to read the results

At each point the arrangement calculates a position afresh. Deviation is the horizontal distance between the calculated position and the reference position at that point. As a percentage, it is that distance divided by the distance moved since the previous point, multiplied by 100. The start point has no previous point and is excluded.

All values here belong to a synthetic sample — not a measurement. Point 0 is excluded from the metre and percentage summaries. The series table gives the across-sensor summaries in centimetres to one decimal, because laboratory deviations are a few centimetres; the individual sensor tables retain metres to two decimals. The percentage columns retain their own source values rather than being recalculated from rounded centimetres.

The band is read per run; no trend across runs is computed or claimed. Run order identifies the monthly sequence, not an improvement or deterioration. The track panels use labelled metre scales, and the percentage panels use point index horizontally. Sensor labels and line styles distinguish the traces as well as colour.
