Airborne positioning at 100 km/h and 250 km/h

Summary

This case is built on a synthetic sample — not a measurement — to fix the record’s layout; it is published as a labelled illustration and is replaced by recorded runs as they are approved. The airborne case concerns how per-point deviation relates to the distance moved per interval at two nominal speeds. The synthetic series illustrates reference and calculated tracks, horizontal deviations and elevation columns. Its percentage panels sit side by side on one scale. It establishes no measured airborne performance or certification.

What this case aims to show

The question for the aircraft assessment is whether and how per-point deviation changes with the distance moved per interval, where that step is long. In this synthetic sample — not a measurement — the two run layouts illustrate how to read step length alongside horizontal deviation in metres and as a percentage. The sample establishes no observed relationship between aircraft speed and positioning performance.

The arrangement

In the synthetic sample — not a measurement — the platform is an aircraft and the reference is a satellite GPS receiver on the same platform. The sample represents 8 sensors and identifies the software version as SAMPLE. Its point tables include reference and calculated elevation as well as north and east position. All positions are expressed relative to each run’s start point, identified only by its gps_loc_code.

The task

The synthetic sample — not a measurement — is read as run 1 of 2, G-SAMPLE-004, followed by run 2 of 2, G-SAMPLE-005. The nominal speed changes from 100 km/h to 250 km/h. Both sample entries have a duration of 600 s, an interval of 30 s and 8 sensors. Each contains 21 points, including the start point.

The reference and calculated sensor positions remain paired at each point. The sequence follows the case’s specified order, not the start times. Aircraft attitude and operating conditions are not supplied by these synthetic entries.

How to read the results

At each point the arrangement calculates a position afresh. Deviation is the horizontal distance between the calculated position and the reference position at that point. As a percentage, it is that distance divided by the distance moved since the previous point, multiplied by 100. The start point has no previous point and is excluded.

Every value here belongs to a synthetic sample — not a measurement. Point 0 is excluded from the metre and percentage summaries and from the median step length. Each reference step is counted once for that median. The series table retains each run’s own minimum, median and maximum; it does not calculate a trend across runs.

Both elevation columns subtract the same reference elevation at point 0, so an initial difference between calculated and reference elevation remains visible. These columns describe vertical position; the deviation summaries are horizontal and contain no vertical error calculation.

The track panels have separate labelled metre scales. The two percentage panels share one vertical scale and use point index on the horizontal axis; read the run’s interval and elapsed-time values with those indices.
