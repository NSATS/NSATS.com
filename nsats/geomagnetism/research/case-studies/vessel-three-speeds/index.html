Positioning on a vessel at three speeds (5, 10 and 20 knots)

Summary

This case is built on a synthetic sample — not a measurement — to fix the record’s layout; it is published as a labelled illustration and is replaced by recorded runs as they are approved. The vessel case concerns how per-point deviation relates to the distance moved between observations at different nominal speeds on open water. The synthetic series places reference and calculated positions alongside each other and illustrates the metre and percentage summaries. It establishes neither positioning performance at those speeds nor behaviour in other sea states.

What this case aims to show

The question for the vessel assessment is whether and how per-point deviation changes with the distance moved per interval on open water. In this synthetic sample — not a measurement — the three run layouts illustrate how to read that distance beside the deviation in metres and as a percentage. The sample supplies no observed relationship between vessel speed and positioning performance.

The arrangement

In the synthetic sample — not a measurement — the platform is a vessel on open water and the reference is a satellite GPS receiver on the same platform. The sample represents an arrangement with 8 sensors and identifies the software version as SAMPLE. The reference and calculated tracks use metres north and east of each run’s start point; that start point is identified only by its gps_loc_code.

The task

The synthetic sample — not a measurement — is read in the case’s specified order: G-SAMPLE-001, G-SAMPLE-002 and G-SAMPLE-003, shown as run 1 of 3 through run 3 of 3. The nominal speed changes from 5 knots to 10 knots and then 20 knots. In all three sample entries, the duration is 600 s, the interval is 30 s and the sensor count is 8. Each entry contains 21 points, including the start point.

The reference track, calculated sensor tracks and point summaries belong to the same sample entry. The sequence is the order specified for this case, not an ordering by start time.

How to read the results

At each point the arrangement calculates a position afresh. Deviation is the horizontal distance between the calculated position and the reference position at that point. As a percentage, it is that distance divided by the distance moved since the previous point, multiplied by 100. The start point has no previous point and is excluded.

All values here belong to a synthetic sample — not a measurement. Point 0 is excluded from both metre and percentage summaries. The median step length uses each remaining reference step once, rather than counting it again for every sensor. Each series row retains that run’s minimum, median and maximum; no trend across runs is calculated.

The track panels retain their own labelled metre scales, so equal panel sizes do not imply equal path lengths. The percentage panels use point index on the horizontal axis. Read the run’s interval and elapsed-time values with those indices.

Limitations

Synthetic rows; no limitations recorded.

The sample register contains no disturbance observations or sea-state description. Their absence is not evidence of an undisturbed vessel run. The sample values illustrate how to read the case; they are not observations about NSATS’s arrangement.

What this case does not establish

  • Measured positioning behaviour at the sample speeds, at other speeds or in other sea states.
  • Readiness for a particular use or a comparison with another positioning technology.
  • Anything about a licensee’s vessel or a customer outcome.
