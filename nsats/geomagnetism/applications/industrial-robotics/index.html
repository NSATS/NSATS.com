NSATS / NSATS Geomagnetism / Geomagnetic positioning applications

Industrial and warehouse robotics

Mobile robots need location information as part of carrying out tasks in a workplace. NSATS geomagnetic positioning provides a location input, based on Earth’s magnetic field, within a licensee’s industrial robotics system. Intended applications include warehouses and underground metro maintenance areas.

On this page

  1. Location within a task
  2. The operating workspace
  3. Location within the robot’s work

Location within a task

A robot may need to identify where it is collecting an observation or performing an operation. A positioning input can be considered alongside the other information used by the robot’s software. The task determines the precision and frequency of position updates that make the input useful.

A robot’s task state records whether its assigned operation is waiting, in progress or complete, alongside the location where the work belongs.

The operating workspace

Factories, warehouses and underground metro maintenance areas contain machinery, metal structures and changing arrangements of equipment. A representative evaluation should reflect the workspace and the robot’s expected movement. It should also examine how the positioning implementation relates to the surrounding platform.

The surrounding platform includes the robot’s chassis, power supply, computing resources and the software that consumes position information. The chassis carries the equipment through the workspace; the electrical and computing resources support the tasks running during that movement. A representative evaluation runs the robot’s intended task with the workplace activity expected during its use.

A workplace can contain access areas that are occupied temporarily by goods or other equipment. The application must decide whether occupied access areas require waiting or an operator’s decision.

In a metro service gallery, the task may follow a maintenance walkway past cable routes, ventilation equipment and service cabinets. Route planning, obstacle handling and access permissions belong to the surrounding robotics system; the location input identifies the place associated with the work.

Location within the robot’s work

An inspection robot in an underground metro maintenance area may need to record where it observed a problem with an equipment cabinet or cable installation. The position input identifies the place associated with the observation, while the robot’s software manages the task and the resulting record. This is one role for geomagnetic positioning within a wider robotics system.

In this illustrative underground scenario, direct GPS satellite reception is unavailable. Each robot incorporates a geomagnetic location chipset implementing NSATS’s licensed positioning technology. The chipset supplies location information to the robot’s software, which checks the task assignment and records the inspection.

In an illustrative metro inspection task, a robot approaches a service bay after its original assignment has been transferred to another robot. Its software checks the current assignment before starting work there. Reaching the previously assigned location does not establish that the original inspection is still required.

Compare the warehouse robot scenario, which illustrates the same distinction between a location event and the application’s task assignment in a different workspace.
