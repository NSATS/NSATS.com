Emergency response and remote operations

Field equipment can need location information in remote places or disrupted environments. Geomagnetic positioning provides a location input for devices supporting response teams, remote inspection and other location-dependent tasks.

On this page

  1. Local position information
  2. Reporting to another location
  3. Information for a field team

Local position information

A field device can present location to its user or record it with an observation. The task should define what level of location detail is useful and how frequently it needs to change. Equipment intended for difficult environments also needs application-specific handling of uncertain or unavailable information.

A field application can distinguish a retained position from a current one and indicate when the information is unsuitable for the action the user is attempting.

In an illustrative field inspection, a device has no current position when its user records an observation. Its application keeps the last position visible with its earlier observation time. The new note needs to retain the fact that its location was unavailable, so a colleague does not read the earlier position as the place where the new observation occurred.

Reporting to another location

Where a team or control centre needs to receive a position, the application requires a reporting channel as well as position determination. The communications arrangement, device power and operating conditions should be considered together when planning the complete system.

A reporting channel is the means by which a device’s information reaches another party. The communication equipment needs an electrical supply, and a connection usable where reporting is required. Those needs are considered together: a device may determine its position locally while having no usable connection at the place where its user needs to send a report. Planning the reporting task includes when transmission is needed and what the application does if that connection is unavailable.

A field report may be sent, received and acted on at different times, so a coordination application needs to distinguish those events.

Information for a field team

The local position function and remote reporting serve different tasks:

Location taskWhat supports it
Show position to the user on the devicegeomagnetic input with the device's software
Record position with an observation or user reportgeomagnetic input with the device's software
Send position to a remote team or control centrea separate reporting channel (communications arrangement), planned with device power and operating conditions

Practise reading position status, including an older displayed position and an application that clears its display.
