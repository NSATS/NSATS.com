NSATS Design

Colour

The website’s three colour themes share the same neutral colours for text, backgrounds and dividers. Each theme identifies a group of sections, alongside section names that tell readers where they are without relying on colour alone.

Three themesShared coloursWhere each theme is usedIn useFor developers

Three themes

Each theme runs from its deepest colour to its lightest tint, with a role and a copyable HEX value for every swatch. The contrast list identifies the colour pairs that meet the normal-text contrast target.

NSATS cyan

Used for Applications, MyNSATS account access, Contact, Website policies and reporting, Recruitment privacy notices, Email subscriptions, Search and Sitemap

  • DeepContrasting bands and page heads#062C38RGB 6, 44, 56
  • HoverPressed and hovered actions#004E63RGB 0, 78, 99
  • ActionLinks and primary buttons#006B85RGB 0, 107, 133
  • AccentDecorative highlights only#00CCFFRGB 0, 204, 255
  • TintQuiet panels and callouts#E8F7FBRGB 232, 247, 251

NSATS cyan uses blue-green for links and buttons, bright cyan for highlights and a pale tint for panels. It identifies application pages, MyNSATS account access, contact, website policies and reporting, recruitment privacy notices, email subscriptions, Search and Sitemap.

Illustration palettes and layout templates are separate from page colours.

In use

For developers

Download the colour definitions as CSS custom properties for the three themes and their shared colours. With that stylesheet loaded, set data-theme="cyan", data-theme="carbon" or data-theme="royal" on a container to apply the corresponding colour properties.

:root { --ink: #161616; --muted: #525252; --paper: #FFFFFF; --layer: #F4F4F4; --line: #D8D8D8; --focus: #FFDD00; --max: 1440px; }
[data-theme="cyan"] { --action: #006B85; --hover: #004E63; --accent: #00CCFF; --tint: #E8F7FB; --deep: #062C38; }
[data-theme="carbon"] { --action: #0F62FE; --hover: #0043CE; --accent: #78A9FF; --tint: #EDF5FF; --deep: #161616; }
[data-theme="royal"] { --action: #264566; --hover: #18334F; --accent: #55B9BC; --tint: #EEF4F7; --deep: #132B42; }
