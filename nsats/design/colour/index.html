NSATS Design

Colour

NSATS uses three colour themes across its website: NSATS cyan, Carbon blue and Royal blue & teal. Each theme identifies a group of sections, while shared text and background colours give the pages a consistent appearance. Section names and navigation identify where readers are without relying on colour alone.

Three themesShared coloursWhere each theme is usedIn useFor developers

Three themes

Each theme contains five colours for headings and contrasting bands, links and buttons, decorative highlights, and pale background panels. Every swatch shows its intended use and its HEX and RGB codes, which identify the colour numerically.

The contrast examples show which text and background combinations meet the 4.5:1 minimum for normal text. This checks the listed colour pairs; it does not establish the accessibility of a complete page.

Shared colours

All three themes use the same six shared colours for text, backgrounds, dividers and keyboard focus. Dark text sits on white or light grey surfaces, while muted grey supports secondary text and input borders.

Focus yellow marks the control reached through keyboard navigation and is paired with a dark outline. The pale divider colour is reserved for decoration and should not be the only visible boundary of an input or other control.

Theme selection follows the website section, so Quantum and Geomagnetism each use all three themes. Financial Information uses Royal blue & teal within MyNSATS, while other account screens use NSATS cyan. Privacy notices also use NSATS cyan, including those within Careers, and forwarding pages use the theme of their destination.

These assignments govern website page colours. Illustration palettes and layout templates are selected separately.

In use

These examples use the same layout and text to show how each theme treats headings, links, buttons and supporting information. They are visual samples; their links and buttons do not perform actions.

For developers

The downloadable stylesheet defines the three themes and shared colours as CSS custom properties: named values that website styles can reuse. After loading it, set data-theme="cyan", data-theme="carbon" or data-theme="royal" on a container to select the corresponding palette.

Use those properties in the styles for text, backgrounds, borders and controls. Selecting a theme provides its colour values; it does not create a complete page layout.

:root { --ink: #161616; --muted: #525252; --paper: #FFFFFF; --layer: #F4F4F4; --line: #D8D8D8; --focus: #FFDD00; --max: 1440px; }
[data-theme="cyan"] { --action: #006B85; --hover: #004E63; --accent: #00CCFF; --tint: #E8F7FB; --deep: #062C38; }
[data-theme="carbon"] { --action: #0F62FE; --hover: #0043CE; --accent: #78A9FF; --tint: #EDF5FF; --deep: #161616; }
[data-theme="royal"] { --action: #264566; --hover: #18334F; --accent: #55B9BC; --tint: #EEF4F7; --deep: #132B42; }
