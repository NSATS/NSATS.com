Manuals

The NSATS manuals explain two software designs: a proposed demonstration for reducing and restoring files, and an interface for collecting magnetometer measurements and operating equipment. They help readers follow the intended workflows, interpret commands and examples, and understand the responsibilities of an application using either design.

Both collections are public online documentation. They contain reading exercises rather than executable software, and their examples do not establish measured performance or compatibility with a particular implementation.

  • Documentation by task

    Use the table to choose the explanation needed for your work. The compression material follows a file through one running session; the magnetometer material follows measurement collection and equipment operations without defining how geographic position is calculated.

  • Compression and restoration manuals

    Begin with the technical overview and workflow to understand what happens to the original file, the reduced output and the information retained in the program’s memory. Restoration depends on matching session data, so the smaller file is not a standalone backup. The original file remains the reference for checking whether restoration has recovered the expected contents.

    The command reference and worked examples explain the proposed operations and their expected responses. The integration guide then assigns responsibilities for managing the session, handling incomplete work and checking results, while the security design describes intended safeguards and their limits.

    These six manuals concern a proposed C software demonstration. Licensed Temporal Compression and the wider Quantum technologies are explained separately.

    Read the compression and restoration manuals →Command reference →Compression integration guide →Security design →Temporal Compression →Quantum technologies →

  • Magnetometer manuals

    Begin with the developer walkthrough to follow connection, authorised device access and measurement collection. The hardware and data interface explains the records needed to interpret a response, while the command reference describes the operations and their prerequisites.

    The processing and equipment manual covers signal processing, calibration, self-tests and averaging. The responses and examples manual shows how to interpret illustrative records, including missing data. Together, the five manuals explain acquisition and equipment operation; they do not supply a tested device connection or a method for calculating geographic position.

    Read the magnetometer design manuals →Magnetometer interface reference →Geomagnetism integration guide →Positioning from Earth’s magnetic field →
