High-performance computing

NSATS’s processor, memory and interconnect technologies support the demanding calculations used in scientific simulation and engineering analysis. They address the work of performing operations, supplying data and reusing information across calculation stages, helping a system complete the required analysis sooner.

High-performance computing often divides work among many processors. Some calculations can proceed independently, while others must wait for an earlier result. NSATS’s gate designs support parallel computation where those dependencies allow it, with the practical speed improvement determined by the calculation and the way its processors and memory are arranged.

Performing calculations and reusing earlier inputs

For supported operations, NSATS’s gates and in-built memory allow a processor to obtain a corresponding value through a lookup instead of calculating the input–output relationship afresh. This can reduce the work required at that stage, although accessing memory and moving information remain part of the operation.

The gates retain input and output information so that an earlier input can be regenerated and supplied to a subsequent calculation. This supports limited, non-thermal reversible computing at component level. Full reversibility across the complete system remains the subject of continuing research.

Reusing an earlier input is useful where later work depends on information from a preceding stage. The implementation must retain the information needed for that recovery and associate it with the correct operation. It must also deliver the recovered input to the calculation that needs it, preserving its meaning throughout the exchange.

Supplying processors with working data

A faster calculation helps only while its inputs are available. NSATS’s memory technology increases effective working capacity, and its internal connections support faster exchanges between memory and processors. The quantum-classical bus carries electrical signals with more than two states, allowing quantum-encoded information to pass between components over interfaces of unchanged physical width.

A simulation may hold its inputs, temporary values and developing result in memory at the same time. Several calculations running together can also compete for the same memory and connections. The system therefore needs enough usable capacity and access performance for the work that overlaps, as well as sufficient processing capability for each calculation.

Completing the analysis

The benefit to an engineering or research team is the time and resources required to obtain its result. That includes preparing inputs, performing calculations, retaining information needed again and delivering the final output. A faster gate or a larger working set contributes to that outcome through its role in the complete task.

Energy use follows the same principle: the calculation, memory and transfers all contribute. NSATS’s technology is designed for lower energy use, while the result for a particular analysis depends on its workload and implementation. The comparison must therefore cover equivalent work and the required result, including any preparation needed before the calculation starts.
