NSATS / Quantum technologies / Reversible Computing

State reconstruction

Reversible computing retains the information needed to work back through an operation. NSATS has achieved reversible computing at component level: its swap gates retain input and output information and work reversibly in a limited form. An external processor uses the retained information to regenerate earlier inputs, which can then be used in subsequent calculations. Full reversibility across the complete system is the subject of continuing research. NSATS describes this arrangement as processor-assisted, semi-reversible computing.

Reversible ComputingState reconstruction

Purpose

An earlier input may be useful when a calculation needs to be retraced or its prior information used again. The gates retain the information required, the external processor regenerates the earlier input, and the surrounding system supplies it to the step that needs it.

In ordinary software, a later calculation may use the original input under changed parameters.

Further explanation

A public example

Adding three and seven gives ten. Adding four and six also gives ten. If only the total is kept, it does not identify the original pair. Suppose the operation retains both the total, ten, and the first input, three. Subtracting three from ten returns seven, so the pair can be identified. The retained output is the total together with the supporting input. This arithmetic example illustrates information preservation; it does not describe NSATS circuitry or compression.

In an illustrative engineering calculation, a program uses a component’s original dimensions and material properties to calculate its response to a load. A later stage examines another load case using those original inputs. The intermediate response belongs to the earlier case; the dimensions and material properties remain inputs to the new calculation.

The later stage needs the earlier input, and obtaining it depends on the information retained with the result, rather than the result alone.

Saving inputs during computation requires processing time and storage space. An assessment therefore includes the work of retaining and accessing supporting information.

Processor-assisted, semi-reversible computing — diagram and explanation

The implementation boundary

The swap gates retain input and output information within the circuit. An external processor uses the retained information to regenerate an earlier input or generate the corresponding output. The surrounding system, designed by the licensee, makes the regenerated input available to the component performing the later calculation when that stage begins.

An assessment can include the gates, retained information, controller, processor and storage, together with transfer where applicable. A subsystem can be considered if its inputs, outputs and external dependencies are explicit. The boundary defines which steps are tested and which resources are counted.

Recoverability concerns whether an earlier input can be obtained from the information available. Logical reversibility requires each step within the chosen boundary to preserve enough information to identify the state before it. A recoverable transition may also be reversible, but recovery alone does not establish that all the steps meet this test.

“Semi-reversible” indicates that reversibility is achieved at component level, in the gates; the continuing research concerns the complete computation, including the processor’s work. It is an NSATS working description, not an established scientific category or a measured degree of reversibility.

A licensee can incorporate the methods into software, programmable hardware or a custom chip. The intended task determines where operations take place, what information is retained and how it is supplied to later processing.

NSATS sells technology licences, not chips. Its technology helps licensees manufacture their own chips.

What the boundary leaves out

This public account describes the behaviour a licensee specifies and evaluates: the inputs supplied, the outputs returned and the earlier inputs that can be regenerated. How the gates retain information, the processor’s internal work and the direction of continuing research remain outside that scope.

Retained earlier inputs need protection alongside current inputs and results in the licensee’s security assessment. Invertibility alone provides no secrecy.
