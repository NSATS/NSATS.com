NSATS

NSATS Quantum

NSATS licences enable classical devices to perform operations based on quantum mechanics, at room temperature. The technology operates without super-cooling. The portfolio covers computational methods and software, chip and system designs. NSATS sells technology licences, not chips. Its technology helps licensees manufacture their own chips. Licensees build the software, chips, devices or systems.

Computation, memory and data movement

Demanding workloads can be limited by calculation, memory access or the time spent moving data. NSATS’s technology addresses these constraints together, from how information is represented to how it is processed, stored and transferred.

Quantum-classical technology applies computational relationships drawn from quantum mechanics in classical circuitry. Choices about software, hardware and protection connect the technologies across the portfolio.

A workload is the work a system is asked to complete, rather than a single instruction. An operation may be straightforward while the surrounding task involves repeated requests for information.

A workload description includes the shape of the data and how it is requested. Reading a collection in order and repeatedly looking up individual records can place different demands on the same computer.

Technology

NSATS’s computing technology covers:

Quantum-Classical Computing

NSATS’s technology applies computing methods drawn from quantum mechanics in classical electronic circuits. Licensees implement it through specially designed classical chipsets, not off-the-shelf third-party hardware. These chipsets operate at room temperature. The technology includes quantum-inspired gates: building blocks that define operations on information. These methods provide the basis for reversible computing, memory and processing, and licensees incorporate them into software and chip designs for computing systems.

In ordinary computing, the output of an operation can supply the next operation. A complete calculation therefore depends on both the operations chosen and their connections.

Reversible Computing

Reversible computing retains the information needed to work backwards from a calculation to its original input. NSATS has achieved reversible computing at component level: its swap gates retain input and output information within the circuit and work reversibly in a limited form, so an output can be traced back to its input. An external processor uses the retained information to regenerate earlier inputs, which can then be used in subsequent calculations. Full reversibility across the complete system is the subject of continuing research. NSATS describes this arrangement as processor-assisted, semi-reversible computing. Some operations can be reversed directly; others keep supporting information alongside a result or in memory.

In ordinary software, a rounded result can correspond to several original values. Identifying the particular input requires information that distinguishes those possibilities.

Temporal Compression

Temporal compression increases effective capacity: more data can be stored or retrieved within the same physical storage resource. The physical size of the drive stays unchanged. Classical data is encoded using quantum-mechanical logic. NSATS’s processor-assisted, semi-reversible computing contributes to compression, so the drive holds more data.

The increase depends on the drive, how the licensee uses the technology and where the licensed gates, buses and computational technologies sit in the licensee’s design. For existing drives and RAM, the licensee adds a specially designed classical chipset or controller built with the licensed technology to manage the intermediate operations when data is stored or retrieved. The drive or RAM itself remains ordinary classical storage. This is not a software-only upgrade or a drop-in change; integration is part of the licensee’s design.

A storage specification distinguishes the collection an application needs to keep from the hardware allocated to it. The collection includes the records themselves and information used to identify them.

Memory and RAM

RAM holds the working data programs need while they run. Through the licensee-added chipset or controller described under Temporal Compression, existing classical RAM holds classical data encoded using quantum-mechanical logic, so computer buses send and retrieve it faster. NSATS’s licensed technology supports greater usable memory capacity. It is designed for lower energy use. The technology addresses both that capacity and access to working data, including communication between memory regions, processors and memory controllers.

NSATS’s licensed Quantum technology enables one component to perform both storage and working-memory roles in a solution designed and built by the licensee, while existing drives and RAM remain ordinary classical storage. This provides a second implementation route alongside the controller route described above. Retained storage keeps information for later use, while working memory supplies data to running programs; these remain distinct functions within the component. The component exchanges data with processors over the quantum-classical bus described under Processors and Internal Buses.

Chip Design

NSATS’s portfolio includes several quantum-inspired gate designs that improve the efficiency of operations carried out in chips and increase chipset speed. The gates introduced under Quantum-Classical Computing can be combined within a computing design. The designs can be incorporated into programmable hardware or custom chips; how functions are divided between software and hardware depends on the licensee’s design.

In an ordinary design, a function’s inputs and outputs are agreed before its implementation is chosen. Other parts of the system depend on that agreement when they exchange information with it.

Processors and Internal Buses

Buses and interconnects carry data between processors, memory and other components inside an electronic device. NSATS’s technology provides new connection and transfer processes for these paths, including the quantum-classical bus. The bus carries electrical signals with more than two states, beyond binary 0 and 1, which enables faster processing, data transfer and decision making within a quantum-classical electronic device. It supports new applications that depend on the exchange of data between components, alongside the calculations, memory access and coordination needed to complete a task.

An ordinary internal connection carries requests as well as the data requested. The receiving component must know which action to perform and which information the request concerns.

Data Movement

Moving data is part of the work performed by a computing system. NSATS’s technology handles internal data exchanges and the processing associated with transfers between systems, including preparation at a sending endpoint and reconstruction at a receiving endpoint. A task may fetch information, perform a calculation and pass the result onwards. The technology treats these processing and transfer steps together.

A program can copy data without changing its contents. That copy still occupies memory and takes part in the work needed to complete the task.

Quantum-Classical Networking

NSATS’s technology uses concepts from quantum mechanics to deliver faster data transfer across classical networks. Quantum-classical network cards at both the sending and receiving ends of a connection enable high-speed data transfer, and the data passes through ordinary routers in between. The chips in these cards handle processing around transmission and receipt, including reconstruction of the transmitted information. The design supports compatibility with both connected systems and performance across the full journey, including transfer and routing.

An endpoint is a system where a transfer begins or ends. Routers forward information between networks on the way to its destination.

Post-Quantum Security

Post-quantum security addresses the future threat that quantum computing poses to today’s security. NSATS’s post-quantum security technology uses classical computing methods inspired by quantum mechanics and is designed to protect information during processing, in memory and along internal data paths. Licensees build this security into their own chips and systems, bringing security architecture, key handling and protected processing into the implementation. NSATS’s post-quantum security is not a separate product.

A threat model identifies information to protect, authorised users and the parties and actions the design guards against. It includes assumptions about access to the equipment and its software.

Applications

An application gives the technology a purpose: a calculation to finish, information to retain or data to make available elsewhere.

Applications include:

High-Performance Computing

Quantum-inspired gates in classical machines provide a route to reversible computing and faster processing. NSATS’s technology supports high-performance systems carrying out demanding calculations, such as scientific simulations and engineering analysis, and new computing platforms using processor-assisted, semi-reversible computing. The application brings together gate design, processors, memory and internal connections to complete computational tasks. The licensed technology is designed for lower energy use.

A simulation calculates the behaviour of a model from its inputs. Dependent calculations must receive the results they need before they can continue.

High-performance computing →

Data-Intensive Computing

Analysing large datasets requires a system to read information, hold working data in memory, perform calculations and store or transfer the results. NSATS’s memory and data-movement technology supports the design of these steps, from the way an analysis system supplies data to its processors to how it manages information as the work progresses. In licensee-built data-centre systems, with existing drives and memory connected through the added chipset or controller described above, fewer hard drives and less memory are needed to store data, existing memory processes existing binary data faster, and the chipsets run with lower heat than conventional computing.

A dataset is a collection organised for a particular use.

Data-intensive computing →

Temporal Storage

Temporal storage applies NSATS’s compression approach to increase the amount of data stored on a drive of a given physical size. Effective capacity depends on processing time, not only physical size. A temporal drive is better described by how much data it can process and store per second than by a fixed capacity. The licensee’s chipset or controller manages the intermediate operations used to store the data and retrieve it when needed. Uses include archives and systems that continually collect information, holding more data within the storage available.

An archive keeps material for later reference. Its catalogue identifies individual records so an application can request particular material rather than the whole collection.

Temporal storage and memory →

Temporal RAM and Computer Memory

Temporal memory applies time-based representation to the data a running program needs. Through the added chipset or controller, NSATS’s licensed technology increases usable memory capacity and supports high-speed RAM. The licensed technology is designed for lower energy use. Applications include programs that work with large amounts of data and systems where memory resources constrain the size of a computing task. In a licensee’s design, one component built with the licensed technology can perform both the working-memory and the retained-storage role, as described under Memory and RAM.

A running program may hold its input, temporary workspace and an unfinished result at the same time. Its largest memory demand can occur during the calculation.

Temporal storage and memory →

Security-Sensitive Computing

Systems handling confidential information need protection during computation, storage and transfer. NSATS’s security technology addresses these stages together, using classical computing methods inspired by quantum mechanics to protect against the future threat quantum computing poses to today’s security. Applications include computing systems in which sensitive data must be handled throughout a task, from its arrival in memory through processing and the transfer of results.

In an illustrative reporting task, a reader may see a summary while access to its confidential source records remains restricted.

Security-sensitive computing →

Embedded and Edge Systems

Computers built into equipment must operate within constraints on power, space and cost. NSATS’s gate designs, reversible-computing methods and connection processes support the design of such systems. Settings include industrial controllers and local computers that process operational data. The licensee’s design choices concern which functions run in software, which belong in hardware and how data moves between them.

An embedded program often reads equipment signals and responds while the equipment is operating. The task includes maintaining that interaction alongside other computing work.

Embedded and edge computing →

Network Transfer

NSATS’s technology applies quantum-inspired processing at both ends of a classical network to deliver faster data transfer. Paired quantum-classical network cards handle the work of sending and receiving information, while the data passes through ordinary routers in between. Applications include transferring large datasets between computers, long-distance transfer through ordinary routers, and transfer over wireless, optical and wired links. The improvement concerns the complete journey from the source system to usable information at the destination.

A receiving program needs to identify which data has arrived and whether it is ready for use. Receiving traffic and completing an application request are distinct events.

Performance Evaluation

Performance evaluation compares an implementation with a defined baseline under stated operating conditions. Relevant measures include processing time, data-transfer rate, memory access time and retrieval accuracy. The comparison should cover the full system and reflect the application’s requirements.

A baseline is the reference against which a result is interpreted.

Operating conditions include the input collection, equipment configuration and other work running at the same time. A comparison should state which of these were held constant.

Performance evaluation →Quantum research and evidence →

Software and Hardware Implementation

A licensee can implement a computational method in software, programmable hardware or a custom chip. Software carries out functions through a program; programmable hardware allows selected hardware functions to be configured; a custom chip incorporates functions into a dedicated design. The choice depends on the application and its exchanges with memory and other components.

A later change to a function may require a program update, a new hardware configuration or a revised chip design. Maintenance requirements belong in the choice from the outset.
