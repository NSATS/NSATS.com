Interactive demonstrations

These browser-based illustrations explain two different tasks: associating a device’s location with an inspection or operating record, and retrieving a stored file with the expected contents. The Geomagnetism walkthrough uses example locations and events, while the Temporal Compression walkthrough follows supplied sample files through an illustrated storage and retrieval process.

Neither walkthrough measures the performance of NSATS technology. They require no connected equipment or MyNSATS account, although access requires email verification. The Temporal Compression walkthrough also performs an actual browser check of the supplied sample file, separately from its illustrated storage stages.

Geomagnetism

NSATS’s Geomagnetism technology determines location using Earth’s magnetic field without relying on live GPS satellite signals. An application can associate that location with an inspection finding, a vehicle event or an asset record, allowing the reader to identify where the recorded activity occurred.

NSATS’s research demonstration arrangement combines its software with a custom magnetometer array connected to antennas and digital signal processing chips. The specified arrangement uses at least eight chips. It measures the magnetic field at the device, including contributions from nearby objects and electrical equipment, before filtering and processing the measurements to determine location.

The browser illustration uses prepared events to explain how that output is read. It distinguishes a new position from a retained earlier position and keeps the application’s inspection, task or handover record separate. No magnetometer is connected to the walkthrough.

Temporal Compression

Temporal Compression enables storage manufacturers to incorporate NSATS gates, connectors and circuits to increase the amount of information that can be retained within a physical storage resource. Existing classical drives require an added chipset or controller to manage the encoding and intermediate storage and retrieval operations. NSATS’s own temporal drive is a research and development demonstration of this technology.

Physical capacity describes the underlying storage resource. Effective capacity describes the amount of original information that can be retained and recovered using it. The achievable increase depends on the data and implementation. Processing time affects how quickly that capacity is made available, while retrieval performance determines how quickly the information can be recovered; neither measure replaces capacity.

The browser walkthrough illustrates a proposed file-service sequence: acceptance of a file, issue of a tracking reference, completion of storage and subsequent retrieval. It uses supplied samples without uploading or storing a visitor’s file. When a sample is retrieved, the browser fetches it from the website and compares its fingerprint with the stated expected value. That check concerns the sample file and does not measure Temporal Compression.

Ways to explore

Choose Start the guided run for an ordered task, or Explore freely to select scenarios and events yourself. In Geomagnetism, examine the selected event alongside its location and original position time. In Temporal Compression, complete the required file comparisons, then select Save file to download the checked sample.

Use Explore freely to select scenarios and events in your own order. You can bookmark a Geomagnetism scenario or return directly to the sample retrieval task. A new visit offers prepared example receipts if your earlier sample receipt is unavailable.

What the current mode means

Interactive illustration means that the locations, events or storage stages have been prepared to explain a task. The Geomagnetism walkthrough does not calculate a position from live measurements. The Temporal Compression walkthrough does not run the licensed compression technology, although its browser does calculate and compare fingerprints for the supplied sample files.

For guidance on assessing a licensee’s implementation, read the Geomagnetism evaluation methods or the Quantum evaluation guidance.

Demonstration datasets and recorded results

The linked Quantum and Geomagnetism demonstration datasets contain generated values used to explain record formats and analysis. They are separate from these interactive walkthroughs and are not measurements of NSATS technology.

Recorded results are a separate collection, available to qualified parties under a signed non-disclosure agreement. Each dataset page provides the relevant access and request routes.

Questions

Which demonstration should I start with?

Choose Geomagnetism if your task needs a location associated with an observation, device or asset. Choose Temporal Compression if your task concerns storing a file, finding its receipt and checking the file returned.

Do I need equipment, software or an account?

The illustrations run in your browser. You can use the supplied events and samples without connecting equipment, installing an SDK or creating an account.

Is the demonstration a performance measurement?

The current mode explains tasks and results using examples. The evaluation pages describe how to assess an implementation, including the evidence and conditions needed to interpret its results.

Does the Geomagnetism demonstration use GPS?

Its location display represents geomagnetic positioning output. A satellite GPS position would be a separately supplied reference, labelled as such. The illustration uses authored locations and does not request your browser’s location.

What is the tracking code?

In the intended file service, it is the reference you keep and submit when requesting your file. The illustration uses clearly marked SAMPLE receipts to explain that role.

Can I send my own file?

The current walkthrough uses the supplied samples. Its optional local comparison lets you select a copy to check in your browser; selecting that copy does not upload it.

Where can developers read more?

Read the Magnetometer SDK design documentation or the Temporal Compression technology page. The compression software design documentation covers a separate software design, with its own operating model.

How do these demonstrations relate to licensing?

They help you identify the task, output and integration questions relevant to your intended implementation. Use those questions when making a licensing enquiry.
