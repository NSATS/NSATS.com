NSATS themes and typography

This page is a reference for designers and developers using NSATS’s website colours and typography. It brings together the three colour themes—NSATS cyan, Carbon blue and Royal blue & teal—with their colour values, section assignments and examples of common page elements.

The font specimens compare NSATS Sans 1.204, the website’s default typeface, with IBM Plex Sans, which is included here as an alternative.

Three website themes

Select a theme to see how its colours appear in the component preview below. The colour cards retain their own palettes, and your selection does not change the colours assigned to other website pages.

NSATS cyan is the default. Where browser storage is available, this page remembers your selection for a later visit. Use Reset selections to return to NSATS cyan and NSATS Sans.

White text on each theme’s action colour exceeds the 4.5:1 contrast target for normal text. The accent colours do not meet that target when used as normal-size text on white; use them for decoration or as backgrounds behind dark text.

Use the muted text colour for input borders where the boundary is needed to identify a control. The pale divider colour is intended for decoration, and focus yellow should be paired with a dark outline so that keyboard focus remains visible against white.

The reference targets are 4.5:1 for normal text and 3:1 for large text and necessary control or state indicators. Labels accompany colour so that colour alone does not carry the meaning. These ratios are calculated from solid sRGB colour values; they do not establish the accessibility of a complete page.

Theme selection follows the website section, so Quantum and Geomagnetism each use all three themes. The Technologies grouping includes both portfolio overview pages, chip design and implementation. Developer manuals use Royal blue & teal, while public resources and white papers use Carbon blue.

Financial Information uses Royal blue & teal within MyNSATS, and recruitment privacy notices use NSATS cyan within Careers. Forwarding pages use the theme of their destination. These assignments govern website page colours; illustration palettes and layout templates are selected separately.

Font testing and limitations

The recorded tests cover several font editions. Native Mac testing used NSATS Clear 1.202 in Word, Pages, Keynote, TextEdit, Preview, Safari, Chrome and Firefox on macOS 26.6.2, at the recorded application versions. Version 1.204 includes later changes to accent placement, spacing and kerning for ď, ľ, ť and Ľ, so the earlier fonts should not be described as identical to the released version.

Windows 11 testing used NSATS Sans 1.203 in Word 2010, Edge, Chrome, Firefox, DirectWrite, GDI, Paint and print, including loading the fonts from the website. The first 1.204 candidate was then tested for accent spacing and Word 2010 kerning. Further corrections were made before release.

The released 1.204 fonts were checked through measurements, rendering on Linux and an independent review that included Safari on macOS. Those checks do not establish that the released files have passed testing on Windows or when installed on a Mac. The developer kits were tested on Linux only.

Outstanding checks include the released fonts on Windows and when installed on a Mac, use on iPhone and Android, and the effect of character-code settings in older software. Reader studies, native-language review and complete checks for clipped characters also remain outstanding. Earlier website-loading and print tests should not be treated as verification of the released fonts in every environment. Approval for NSATS use is a release decision and does not mean these checks have passed.

See the version 1.204 release notes for the recorded test scope and known limitations.

The colours are specified in sRGB for website display. No Pantone or CMYK print equivalents are supplied because the appropriate conversion depends on the printer, paper and output profile.
