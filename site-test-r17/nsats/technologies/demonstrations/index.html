Geomagnetism

Geomagnetic positioning determines location using Earth's magnetic field and supports positioning without reliance on live GPS satellite signals. The technology is developed and available under licence. Its location output can give an inspection finding, a vehicle event or an asset record a place, helping the person using that record understand where something happened.

The specified demonstration arrangement connects NSATS software to a custom magnetometer array connected to novel antennas and digital signal processing (DSP) chips. It takes data from an array of at least eight chips. The array measures Earth's magnetic field at the device, including disturbances associated with its surroundings, such as nearby iron objects, machinery and electrical installations.

NSATS sells technology licences, not chips. Its technology helps licensees manufacture their own chips.

The journey from measurement to a useful record has four parts:

  1. The array measures the magnetic field at the device.
  2. Multiple filters and NSATS's proprietary DSP prepare the incoming measurements for positioning.
  3. NSATS's positioning method determines the location.
  4. The application displays the location on a site plan or map and makes it available as a text record.

The demonstration lets you explore this journey through example events. Select a finding, read its location and time, and distinguish information supplied by positioning from information entered by the application. The display also identifies when it is retaining an earlier position rather than showing a new one.

Intended applications include work underground, indoors, underwater, on the surface, in dense urban areas and in the air. The scenarios focus on practical questions: which fitting needs repair, which task belongs to a robot, and where an asset changed hands.

Temporal Compression

Temporal Compression uses concepts from quantum mechanics to store more data within a given physical storage resource. NSATS has developed a specific hard drive using quantum-mechanical logic as its own research and development (R&D) demonstration of its licensed technology. Licensees build their own drives and systems using the technology.

NSATS licences enable classical devices to perform operations based on quantum mechanics, at room temperature.

Physical capacity describes the storage resource a device contains. Effective capacity describes how much data is stored within it.

Effective capacity depends on processing time, not only physical size. A temporal drive is better described by how much data it can process and store per second than by a fixed capacity.

The file demonstration service is designed to support this sequence:

  1. You would send a file to NSATS over a secure HTTPS connection.
  2. After accepting the complete file and confirming its fingerprint, NSATS would issue a 256-bit tracking code and a Received status.
  3. The storage operation would complete with Stored, or report Failed if it could not complete.
  4. When you needed the file, you would submit the tracking code.
  5. NSATS would decompress the stored file and make it available to download.
  6. You would check the returned file against the original fingerprint.

The browser illustration uses sample files to explain this journey. It illustrates the receipt and storage stages without uploading or storing a visitor's file. When you retrieve a sample, your browser fetches it from this website and calculates its fingerprint. That calculation is a real check of the fetched sample; the receipt is clearly marked SAMPLE.

Try the journey with a research dataset, a maintenance record or a completed interval of sensor readings. Other scenarios explore retrieving the revision a review requires, or making sure the original document is the one you send.

Ways to explore

Start with a guided scenario for a task, a first action and a result to interpret. In Geomagnetism, the takeaway connects the selected event with its location record. In Temporal Compression, finish the required comparisons and select Save file to have the checked sample offered for download.

Use Explore freely to select scenarios and events in your own order. You can bookmark a Geomagnetism scenario or return directly to the sample retrieval task. A new visit offers prepared example receipts if your earlier sample receipt is unavailable.

What the current mode means

Interactive illustration uses example data and scripted stages to explain a workflow. Geomagnetism shows authored location events and application records. Temporal Compression illustrates storage stages and separately identifies the fingerprint calculations your browser performs on actual sample files.

For guidance on assessing a licensee's implementation, read the Geomagnetism evaluation methods or the Quantum evaluation guidance.

Questions

Which demonstration should I start with?

Choose Geomagnetism if your task needs a location associated with an observation, device or asset. Choose Temporal Compression if your task concerns storing a file, finding its receipt and checking the file returned.

Do I need equipment, software or an account?

The illustrations run in your browser. You can use the supplied events and samples without connecting equipment, installing an SDK or creating an account.

Is the demonstration a performance measurement?

The current mode explains tasks and results using examples. The evaluation pages describe how to assess an implementation, including the evidence and conditions needed to interpret its results.

Does the Geomagnetism demonstration use GPS?

Its location display represents geomagnetic positioning output. A satellite GPS position would be a separately supplied reference, labelled as such. The illustration uses authored locations and does not request your browser's location.

What is the tracking code?

In the intended file service, it is the reference you keep and submit when requesting your file. The illustration uses clearly marked SAMPLE receipts to explain that role.

Can I send my own file?

The current walkthrough uses the supplied samples. Its optional local comparison lets you select a copy to check in your browser; selecting that copy does not upload it.

Where can developers read more?

Read the Magnetometer SDK design documentation or the Temporal Compression technology page. The compression software design documentation covers a separate software design, with its own operating model.

How do these demonstrations relate to licensing?

They help you identify the task, output and integration questions relevant to your intended implementation. Use those questions when making a licensing enquiry.
