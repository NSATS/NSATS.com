1. Introduction

This manual covers daily mailbox tasks and optional use with third-party email applications.

NSATS Mail is a secure email service designed for reliable daily use and long-term message retention. This manual explains how to use NSATS Mail through its web-based mailbox interface and compatible email applications.

The goal of this document is to help users understand how to:

  • Access their mailbox
  • Read, send, and manage email
  • Organize messages and folders
  • Configure basic account preferences
  • Use search and filtering effectively

This manual does not cover:

  • Backend system architecture
  • Internal storage or compression mechanisms
  • Administrative or server-level configuration

2. Accessing Your Mailbox

Signing in and understanding session behavior.

2.1 Signing in

  1. Open the NSATS Mail sign-in page in a web browser.
  2. Enter your email address and password.
  3. Submit the sign-in form.

If the credentials are correct, the mailbox interface loads and displays your inbox.

  • Multiple failed sign-in attempts may be rate-limited.
  • Sign out when using shared or public devices.

2.2 Session behavior

  • Your session remains active until you sign out or the session expires.
  • Inactivity for extended periods may require re-authentication.

3. Mailbox Overview

Understanding the main parts of the mailbox interface.

The mailbox interface is divided into functional areas that remain conceptually consistent even if layout details vary.

Common areas include:

  • Folder list: Inbox, Sent, Drafts, Trash, and any custom folders
  • Message list: Displays messages in the selected folder
  • Reading view: Shows the contents of a selected message
  • Actions menu: Reply, forward, delete, move, mark, and other mailbox actions

4. Reading Email

Opening messages and handling attachments.

4.1 Opening messages

  • Select a message from the message list.
  • The message content loads in the reading view.

Unread messages remain marked as unread until opened.

4.2 Attachments

  • Attachments are shown within the message view.
  • You can download attachments to your device.
  • Supported handling depends on your browser and operating system.

5. Composing and Sending Email

Creating messages, attaching files, sending, and drafts.

5.1 Creating a new message

  1. Select the option to create a new message.
  2. Enter one or more recipient addresses.
  3. Add a subject line.
  4. Write the message body.

Messages may be composed in plain text or formatted text depending on your settings.

5.2 Adding attachments

  • Select the attachment option.
  • Choose one or more files from your device.

Large files may take additional time to upload depending on your connection.

5.3 Sending and saving drafts

  • Sending delivers the message immediately.
  • Messages not sent can be saved as drafts automatically or manually.
  • Drafts remain available until deleted.

6. Replying and Forwarding

Responding to messages and sharing messages with others.

6.1 Replying

  • Reply to the sender.
  • Reply to all recipients, when appropriate.

Replies include relevant message context automatically.

6.2 Forwarding

  • Forward sends an existing message to a new recipient.
  • You may add commentary before sending.
  • Attachments are included unless removed manually.

7. Managing Folders

Default folders and creating additional folders.

7.1 Default folders

Standard folders include:

  • Inbox
  • Sent
  • Drafts
  • Trash

Default folders cannot be removed, but can be used normally.

7.2 Custom folders

You can create custom folders to organize messages. Common uses include:

  • Project-based organization
  • Archiving older correspondence
  • Separating personal and work mail

Messages can be moved between folders at any time.

8. Deleting and Restoring Messages

How deletion works and how to recover messages.

8.1 Deleting messages

  • Deleting moves the message to Trash.
  • Messages are not immediately removed from storage.

8.2 Restoring messages

  1. Open the Trash folder.
  2. Select the message.
  3. Move it back to Inbox or another folder.

Messages remain in Trash until manually removed or automatically purged based on service policy.

9. Searching Mail

Finding messages by sender, subject, or content.

The search function helps you locate messages quickly.

You can search by:

  • Sender or recipient
  • Subject keywords
  • Message content

Search typically operates across folders unless you limit it explicitly. For large mailboxes, searches may take slightly longer, especially for very old messages.

10. Message Organization Tools

Markers, sorting, and list views.

10.1 Flags and markers

Messages can be marked to indicate importance or follow-up needs. The available marker types may vary by mailbox configuration.

10.2 Sorting and grouping

Message lists can typically be sorted by:

  • Date
  • Sender
  • Subject

Sorting affects the current view and does not modify stored messages.

11. Spam and Junk Mail Handling

How filtering works and how to review suspicious messages.

NSATS Mail automatically filters incoming messages to reduce unsolicited or malicious email.

  • Suspected spam may be placed in a junk folder.
  • You can review junk messages and mark false positives.
  • Marking messages helps improve filtering accuracy over time.

Sending behavior remains subject to acceptable-use policies.

12. Account Settings

General preferences and security-related settings.

12.1 General preferences

Settings may include:

  • Display preferences
  • Language selection
  • Message preview behavior

12.2 Security-related settings

Users are encouraged to:

  • Use strong passwords
  • Update credentials periodically
  • Maintain a recovery email where supported

13. Using Third-Party Email Clients (IMAP)

Optional access through IMAP-compatible applications.

NSATS Mail supports access via IMAP-compatible email applications.

When using an email client:

  • Messages remain synchronized with the web mailbox.
  • Folder changes reflect across devices.
  • Deletions and moves apply everywhere.

Connection details are provided within account settings.

14. Storage Behavior (User Perspective)

What users should expect from normal operation.

  • There is no need to manage storage limits.
  • Messages and attachments remain available over time.
  • Older messages may take slightly longer to retrieve in rare cases.

In normal daily use, these differences are typically not noticeable.

15. Troubleshooting

Common issues and practical checks.

15.1 Cannot sign in

  • Verify email address and password.
  • Check for typing errors.
  • Confirm network connectivity.

15.2 Missing messages

  • Check Trash and Spam folders.
  • Use search to locate messages.
  • Verify the correct folder is selected.

15.3 Slow performance

  • Large mailboxes or older messages may take additional time to load.
  • Network speed and browser performance can affect responsiveness.

16. Support and Assistance

When you need help beyond this manual.

For assistance beyond this manual, use the official NSATS Mail contact channels.

When reporting an issue, include:

  • The approximate time of the problem
  • The folder where it occurred
  • The message subject (if relevant)
  • Any error message shown

Contact page: Contact

17. Closing Notes

Service expectations and documentation updates.

NSATS Mail is designed to remain predictable and unobtrusive in daily use. Users are not required to manage storage or optimize their mailbox manually. The service is intended to work quietly in the background while users focus on communication.

This manual describes expected behavior from a user perspective and may be updated as features evolve.
