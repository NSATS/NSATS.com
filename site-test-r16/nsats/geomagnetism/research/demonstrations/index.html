Demonstration records

This section is for positioning demonstration records: the set-up, source data, observations and conditions needed to interpret a result.

To explore an example task now, open the Geomagnetism interactive illustration. It follows authored location events and application records. Evidence records and their interpretation remain pending below.

What each record contains

A demonstration record sets out the purpose and task, the set-up and operating conditions, and the source of the recorded data. Its reference, assessment method and observations follow the framework in How positioning is evaluated, with each observation tied to the conditions in which it was made. The record also explains the limitations of what it shows.

Purpose and task
Specimen: attaching positions to inspection findings along an indoor route
Set-up

NSATS software with a custom magnetometer array connected to novel antennas and DSP chips, data from an array of at least eight chips

  • Software version: SPECIMEN-0.0.0
  • Carried or mounted: Specimen: hand-carried at waist height
  • Measurement channels: not shown (no approved channel mapping)

NSATS sells technology licences, not chips. Its technology helps licensees manufacture their own chips.

Operating conditions
  • Environment: Specimen: indoor plant-room corridor
  • Nearby iron objects, machinery or electrical installations: Specimen: operating machinery beside part of the route
  • Movement: Specimen: walking, a stop beside machinery, then reversing to the start

Conditions recorded during the run:

  • Specimen: walking along an open corridor
  • Specimen: stopped beside operating machinery
  • Specimen: reversing towards the start point

Duration and speed are not published for Geomagnetism records.

Data provenance

Recorded:

  • Specimen: position output for each event
  • Specimen: conditions log
  • Specimen: application records
  • Specimen: independent reference

Output format: Specimen: one text record for each event

Positions are kept in a local site frame for checking only. No coordinates, event times, precision or recording files are published.

Intervals without a new position are reported using the device’s own status vocabulary.

Reference

Independent reference (separate from the geomagnetic output)

  • Source: Specimen: surveyed markers at the start and end of the route
  • How obtained: Specimen: markers surveyed before the run and matched to events by the operator
  • Limitations of the reference: Specimen: the survey provider's stated limits apply

Reference values and uncertainty figures are not published.

Method

Specimen: output events were matched to the reference markers and to the application records

How positioning is evaluated

Observations

Specimen: new positions were supplied while walking. While stopped beside machinery, a last-known position was retained and then no position was shown. New positions resumed when moving away.

  1. Event 1

    • Measurement input: All channels reporting
    • Position output: New position supplied
    • Display: Position from this event
    • Conditions: Specimen: walking along an open corridor

  2. Event 2

    • Measurement input: All channels reporting
    • Position output: New position supplied
    • Display: Position from this event
    • Conditions: Specimen: walking along an open corridor
    • Application record (finding): Specimen: bracket marked for inspection

  3. Event 3

    • Measurement input: Some channels not reporting
    • Position output: No new position
    • Display: Last-known position retained from an earlier event (its time is not published)
    • Conditions: Specimen: stopped beside operating machinery

  4. Event 4

    • Measurement input: No channel data
    • Position output: No new position
    • Display: No position shown
    • Conditions: Specimen: stopped beside operating machinery

  5. Event 5

    • Measurement input: All channels reporting
    • Position output: New position supplied
    • Display: Position from this event
    • Conditions: Specimen: reversing towards the start point

Qualitative only: no coordinates, event times, precision, uncertainty figures or other measured values are shown.

Limitations
Specimen: covers a short indoor route under the conditions listed; it does not show behaviour in other environments.
